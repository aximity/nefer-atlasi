## Komutlar

- `npm run dev`: yerel geliştirme
- `npm run build`: üretim derlemesi
- `npm test`: derleme ve ürün sözleşmesi testi

## Temel ilke

Bilgi eksikse altyapı ve açık durum kurulur; eşya adı, özellik, düşme yeri, başarı oranı veya görsel uydurulmaz.

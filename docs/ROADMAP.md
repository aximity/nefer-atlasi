# Yol Haritası

## Tamamlandı — M1: Güvenilir veri çekirdeği

- [x] Eşya, kaynak, görsel kanıt ve doğrulama kayıtlarını ayrı veri dosyalarına taşı
- [x] Kaynak güveni: taslak / tek kaynak / çapraz doğrulandı / çelişkili
- [x] Tarif malzemelerini parça bazında modelle
- [x] Mevcut 25 kaydı satır bazında denetle
- [x] Çelişkili arşiv alanlarını yayımdan ayır
- [x] Yayımlanan yardımcı alanların (seviye, nadirlik ve görünüş ailesi) kanıt kapsamını tamamla

Çıkış kapısı: Her yayımlanan alanın kaynak kimliği ve doğrulama tarihi bulunur.

## Tamamlandı — M2: Gerçek build editörü

- [x] Her yuvada uyumlu eşya seçimi
- [x] Sınıfa göre silah türü doğrulaması
- [x] Ana ve hibrit hedef puanlama modeli
- [x] URL'den build yükleme, kopyalama ve cihazda kaydetme
- [x] Toplamların birim ve çarpan testleri

## Tamamlandı — M3: Tılsım ve yetenek motoru

- [x] Tılsımları sınıf, renk, seri, kademe ve etki türüne ayır
- [x] Gazap taban değeri ile Gazap tılsımı çarpanını ayır
- [x] Yetenek dağılımı ve puan sınırları
- [x] Sinerji ve çakışma açıklamaları

## Tamamlandı — M4: Bağlamsal öneriler

- [x] Bölge/boss veri modeli
- [x] Rakip sınıf ve direnç ihtiyaçları
- [x] Oyun modu uygunluk kanıtı
- [x] Hazır build ile teorik kombinasyon sayılarını ayır

## Sıradaki — M5: Topluluk ve ölçüm

- [ ] Kimlik, build kaydetme ve paylaşma
- [ ] Topluluk build moderasyonu
- [ ] Oy/kullanım olayları
- [ ] Yeterli gerçek veri oluşunca sıralamalar

## Şimdilik yapılmayacaklar

- Kaynaksız meta veya başarı oranları
- Tahmini eşya görselleri
- Araştırılmamış gözlük/yüzük/kolye adları
- Gerçek kullanıcı verisi olmadan popülerlik sıralaması

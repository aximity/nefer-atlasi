# Nefer Atlası Recovery Manifest

Bu manifest, eski ChatGPT Çalışması ile code baseline arasındaki kayıp geliştirme iddialarının ana kaydıdır.

Code baseline: `068af74088dd7eb323717d93f48072e2b3aac703`

Buradaki kategori iskeletleri mevcut veya tamamlanmış özellik iddiası değildir. Eski çalışma geçmişinden somut kanıt çıkarılana kadar ayrıntılar `UNKNOWN`, statü `NEEDS_VERIFICATION`, öncelik ise `UNASSIGNED` kalır.

## Recovery Status Model

| Statü | Anlamı |
|---|---|
| `PLANNED` | Eski çalışmada yalnız konuşulmuş veya onaylanmış. |
| `IMPLEMENTED_IN_OLD_WORK` | Eski ChatGPT Çalışması'nda uygulandığına dair çıktı veya kanıt var; mevcut GitHub kodunda yok. |
| `USER_TESTED` | Kullanıcı eski sürümde özelliği gerçekten denemiş. |
| `FAILED_USER_TEST` | Eski sürümde kullanıcı testi yapılmış ve hata bulunmuş. |
| `NEEDS_VERIFICATION` | Ne kadar ilerlediği veya ne yaptığı kesin değil. |
| `RECOVERED` | Mevcut GitHub koduna yeniden uygulanmış, kullanıcı akışına bağlanmış ve gerekli kapılarda test edilmiş. |
| `REJECTED` | Eski fikir artık uygulanmayacak. |

Bu statüler birbirinin yerine kullanılmaz. Özellikle eski bir mesajdaki “tamamlandı” ifadesi tek başına `RECOVERED` anlamına gelmez.

## Recovery Priority Model

| Öncelik | Anlamı |
|---|---|
| `R0` | Veri kaybı, yanlış hesap veya temel sistem riski. |
| `R1` | Eski çalışmada çalışan önemli kullanıcı özelliği. |
| `R2` | Önemli kapsam genişletmesi. |
| `R3` | UX, kalite veya düşük öncelikli recovery. |

`UNASSIGNED`, bir öncelik seviyesi değildir; kanıt çıkarılmadan R0–R3 tahmini yapılmadığını gösteren geçici işarettir.

- Kanıt, mümkün olduğunda eski mesaj/çıktı kimliği, kullanıcı testi sonucu ve tarih ile kaydedilir.
- Aynı kategoride birden fazla bağımsız recovery davranışı varsa yeni ve benzersiz `REC-XXX` kayıtlarına ayrılır.
- `Evidence`, `Expected Behaviour` ve `Known Problems` alanları kanıt olmadan doldurulmaz.
- `IMPLEMENTED_IN_OLD_WORK`, `USER_TESTED` ve `FAILED_USER_TEST` statüleri açık eski çıktı veya kullanıcı kanıtı gerektirir.
- `RECOVERED` yalnız `AGENTS.md` içindeki Recovery Protocol tamamlandığında kullanılabilir.
